# 🌍 WanderLust – Explore. Discover. Experience.

A full-stack property listing web application built with **Node.js, Express.js, MongoDB, and EJS**.

WanderLust aims to make discovering and exploring properties simple through a clean interface and dynamic listing management.

---

## ✨ About The Project

WanderLust is a web development project focused on building a property listing platform where users can explore property listings and interact with listing data.

This project is being developed step by step, with a focus on backend development, REST APIs, database management, and frontend integration.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to Project Directory

```bash
cd WanderLust
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and configure your MongoDB connection string according to your project configuration.

```env
MONGO_URL=your_mongodb_connection_string
```

Never upload your `.env` file or expose database credentials.

### 5. Run the Application

```bash
node app.js
```

Open your browser:

```text
http://localhost:8080/
```
